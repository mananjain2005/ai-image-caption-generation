# AI Image Caption Generator

An image captioning application built using:

- DenseNet201 (CNN)
- LSTM
- TensorFlow
- Streamlit
- Flickr30k Dataset

## Features

- Upload up to 4 images
- Generate captions automatically
- Modern Streamlit UI
- CNN-LSTM architecture

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
